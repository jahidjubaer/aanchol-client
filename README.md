# Aanchol — Client

Frontend for Aanchol, a semi-luxury Bangladeshi traditional women's fashion brand (Tangail Jamdani first).

**Stack:** React · Vite · Tailwind CSS v4 · DaisyUI 5 · React Router · Motion

```bash
npm install
npm run dev
```

Project docs live in [`docs/`](docs/), starting with [`00-plan.md`](docs/00-plan.md).
